# Ali Iftikhar — Personal Portfolio

A dark cinematic, responsive portfolio built with Next.js App Router, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Requirements
- Node.js 20.9 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000.

## Production build
```bash
npm run build
npm start
```
